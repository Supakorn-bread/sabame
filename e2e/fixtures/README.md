# Player fixture

`player.mp4` is an original four-second animation of a purple rectangle generated by `scripts/generate-media-fixture.mjs` using Chromium's canvas and MediaRecorder. It contains no third-party footage or audio. The generated fixture is dedicated to the public domain under CC0-1.0.

The Thai/English subtitle cues used in tests are original test strings. They establish deterministic player behavior, not evidence of Thai availability in any anime provider.

Regenerate: `node scripts/generate-media-fixture.mjs` (requires Playwright Chromium).
